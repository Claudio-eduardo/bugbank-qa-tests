# BugBank QA Tests

Projeto desenvolvido com o objetivo de praticar **Quality Assurance (QA)** por meio da elaboração de casos de teste, execução de testes funcionais e documentação de bugs encontrados durante a validação da aplicação **BugBank**.

Este projeto foi construído a partir das atividades práticas realizadas no workshop **"QA: a porta de entrada mais acessível para o mercado de TI"**, promovido pela **EBAC**, sendo posteriormente reorganizado e documentado utilizando boas práticas de QA e GitHub.

---

# Objetivos

- Praticar testes funcionais manuais.
- Elaborar casos de teste.
- Documentar bugs encontrados durante a execução dos testes.
- Organizar a documentação utilizando Git e GitHub.
- Desenvolver um portfólio voltado para a área de Quality Assurance.

# Casos de Teste

Atualmente o projeto contempla a documentação dos casos de teste relacionados ao módulo de cadastro de usuários da aplicação BugBank.

Os cenários contemplam:

- Cadastro realizado com sucesso.
- Cadastro utilizando e-mail já existente.
- Persistência indevida dos dados do formulário.
- Validação do campo Nome.
- Navegação para a tela de login.
- Validação de campos obrigatórios.

---

# Registro de Bugs

Os bugs encontrados durante a execução dos testes são documentados individualmente, contendo:

- Descrição do problema.
- Ambiente.
- Passos para reprodução.
- Resultado esperado.
- Resultado encontrado.
- Impacto.
- Sugestão de melhoria.
